# Hi!

I build tools for working with AI coding agents. I'm a platform engineer by background: I build the tools and services that other teams build on.

### What I'm using and refining

- **[i.inc](https://github.com/firstprateek/i-inc)**: a personal company of AI engineers. Agent employees with their own machines and memories take tickets and hand back checked, reviewed, proven PRs.
- **[Sparring](https://github.com/firstprateek/sparring)**: a writing coach in the margin. You write; it interviews you and critiques. Built on AHP and ACP.
- **[Duet](https://github.com/firstprateek/duet)**: couple finances, in harmony. A private, local-first, end-to-end encrypted desktop app for two.

### Made for fun: try them out!

- **[Neon Swarm](https://firstprateek.github.io/neon-swarm/)**: a 3D swarm-survivor game in the browser. Pick a survivor and hold off the horde.
- **[Orrery](https://firstprateek.github.io/orrery/)**: an interactive solar system. Zoom from the whole system down to a single moon.
- **[Slingstar](https://firstprateek.github.io/slingstar/)**: a one-thumb orbital slingshot game. Best on a phone; add it to your home screen.
